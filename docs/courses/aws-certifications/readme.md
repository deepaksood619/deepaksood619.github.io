## AWS Golden Jacket

**AWS Golden Jacket:** An unofficial-yet-recognized award for cloud professionals who hold all active AWS certifications simultaneously (typically ~12, fluctuating as AWS adds or retires exams like the Machine Learning Specialty). It symbolizes dedication and mastery across architecture, security, networking, and machine learning.

- **Requirements:** every currently active, generally available (no beta) certification must be held and valid at the same time; any expired or lapsed credential breaks the streak.
- **How to get it:** historically recipients were AWS employees, AWS Community Builders/Heroes, or staff at AWS Premier Partners/System Integrators. Submit your verified certification record via internal AWS partner channels, regional distribution paths, or event-driven nomination forms (e.g. at re:Invent).
- **Logistics:** recognition comes from the community/ecosystem, so recipients may need to coordinate shipping, batch processing, or production costs through designated regional vendors.
